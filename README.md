# وقفة — Waqfa v2
مساعد تصوير جامعي داخل المتصفح: اختيار مناسبة → اختيار صورة واقعية → محيط أبيض فوق الكاميرا → التقاط صورة.
مشروع مستقل، غير تابع لسامسونج أو هواوي. الصور المرجعية أشخاص مولّدون بالذكاء الاصطناعي.

## التشغيل في Visual Studio Code
1. فكّي ضغط الملف كاملًا. افتحي مجلد pose-assistant عبر File → Open Folder.
2. افتحي index.html ثم اضغطي Go Live (إضافة Live Server).
3. عندما يفتح المتصفح، اختاري مناسبة ووضعية ثم اضغطي «تشغيل الكاميرا» واسمحي بالوصول.
4. لا تفتحي ملف ZIP داخل المحرّر، ولا تستخدمي file:// لتشغيل التطبيق.

## بديل بلا إضافات إذا كان Node.js مثبتًا
من Terminal داخل مجلد المشروع:
```sh
node server.mjs
```
ثم افتحي http://127.0.0.1:5500 . لا حاجة إلى npm install.
أوقفي الخادم بـ Ctrl+C. إذا كان المنفذ مشغولًا، أوقفي الخادم السابق أولًا.
إذا كان Python مثبتًا، يمكنك بدلًا منه استخدام:
```sh
python3 -m http.server 5500 --bind 127.0.0.1
```
على Windows يمكن استخدام `py` بدل `python3`.

## ما الجديد؟
- 3 مناسبات: التخرّج، السفر، والتصوير اليومي؛ لكل مناسبة صورتان.
- 6 صور واقعية مولّدة مدمجة داخل التطبيق بدل الشخصيات المرسومة.
- محيط أبيض يُستخرج من شفافية الصورة المختارة نفسها، مع الرأس والملابس والذراعين والساقين والإكسسوارات.
- تحريك الدليل بالسحب أو منزلقات الموضع، وتكبيره وتعديل وضوحه وعكسه أفقيًا.
- تشغيل الكاميرا الأمامية أو الخلفية عندما يدعم الجهاز ذلك.
- تصوير يدوي أو مؤقت 3/5/10 ثوانٍ، مع تنزيل صورة خالية من الخطوط.
- مساعدة ذكاء اصطناعي اختيارية تقارن الجسم بموضع الدليل، والتقاط تلقائي بعد 3 ثوانٍ من التقارب المستمر.

## خطوات الاستخدام
1. اختاري المناسبة يدويًا ثم صورة الوضعية.
2. شغّلي الكاميرا وثبّتي الجهاز بحيث يظهر كامل الجسم.
3. اسحبي الدليل إلى المكان المناسب واضبطي حجمه. يمكن استخدام «عكس الوضعية».
4. اتبعي الشكل المرجعي. الحدود تشمل الملابس؛ ليس مطلوبًا أن تكون ملابسك بنفس الشكل.
5. اضغطي الالتقاط، أو اختاري مؤقتًا لتتاح لك فرصة الوقوف.
6. الصورة تظهر أسفل الصفحة مع زر تنزيل وحذف المعاينة. تُحفظ من الفيديو فقط، بلا خطوط أو إرشادات.

## المساعدة الذكية
الدليل الأبيض يعمل بمجرد تشغيل الكاميرا، ولا يعتمد على تشغيل النموذج.
يمكن تفعيل «المساعدة الذكية» لتحميل MediaPipe محليًا. يكتشف النموذج نقاط الجسم في الصورة المرجعية ثم يقارن مواضعها بنقاط الجسم في فيديو الكاميرا، مع مراعاة التكبير والتحريك وعكس الصورة والكاميرا.

تقييم التقارب تجريبي: متوسط مسافة النقاط مقسومًا على أقصر ضلع في الفيديو؛ النسبة = max(0,100 − المتوسط × 300). تُقبل الوضعية عندما يكون المتوسط أقل من 0.065 وأسوأ اختلاف أقل من 0.13. هذه عتبات أولية تحتاج تجارب مستخدمين، وليست نسبة دقة للنموذج.

لا يُعطى تقييم عند غياب الشخص أو النقاط اللازمة أو خروج الدليل المطلوب من الإطار. إذا تعذّر استخراج نقاط كافية من وضعية مرجعية، يبقى الدليل البصري والتصوير اليدوي متاحين. لا يمكن ضمان استخراج جميع مفاصل الأجسام المحجوبة بالأكمام أو ثوب التخرج أو الذراعين المتقاطعين. لا يجري تحليل الأصابع أو الإكسسوارات.

الالتقاط التلقائي يُفعّل من قسم المساعدة الذكية، وينتظر 3 ثوانٍ متصلة. تغيير الوضعية أو موضع الدليل يلغي العد. المؤقت اليدوي يعمل دون تحليل ولا يشترط المطابقة.

## الخصوصية
جميع الصور والمكتبة والنموذج وWASM مرفقة محليًا؛ لا توجد طلبات رفع فيديو أو صور، ولا مفاتيح API أو قاعدة بيانات. تُحفظ معاينة مؤقتة في الذاكرة، وتبقى الصورة المنزّلة على جهازك. يتوقف تشغيل الكاميرا عند مغادرة التبويب، ويمكن تشغيلها ثانية عند العودة.

## حدود النسخة
- اختيار المناسبة يدوي؛ لا يوجد تعرّف تلقائي على مناسبة المشهد أو توليد وضعيات أثناء الاستخدام.
- شخص واحد في الكاميرا. ست وضعيات جاهزة فقط.
- المساعدة الذكية تقديرية؛ الملابس الفضفاضة والاحتجاب والإضاءة والزوايا قد تقلل دقتها.
- تمت مراجعة الصور وفحص الربط والملفات واختبار حسابات الدليل والتقييم آليًا؛ لم تُجرَ تجربة كاميرا فعلية أو مراجعة مرئية بمتصفح في بيئة إعداد النسخة. يلزم اختبار جهاز العرض قبل التسليم.

## الجوال
الواجهة متجاوبة. لتشغيل الكاميرا على الجوال استضيفي المشروع عبر HTTPS. عنوان localhost على الجوال لا يفتح خادم اللابتوب، وعنوان الشبكة المحلي عبر HTTP قد لا يسمح بالكاميرا. هذه الحزمة محلية وغير منشورة.
