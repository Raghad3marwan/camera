دليل تشغيل المشروع

مرحبًا بك في «وقفة»

الإصدار ٢: صور واقعية حسب المناسبة، ودليل أبيض فوق الكاميرا. جميع ملفات نموذج التعرّف على الجسم مرفقة، ولا يتطلب المشروع مفتاح API.

التشغيل في VS Code

  1. فكّي ضغط الملف كاملًا.
  2. اختاري File → Open Folder وافتحي مجلد pose-assistant.
  3. إذا كانت إضافة Live Server مثبتة: اضغطي بالزر الأيمن على index.html واختاري Open with Live Server.
  4. اضغطي «تشغيل الكاميرا» واسمحي للموقع باستخدامها.

طريقة بديلة إذا كان Node.js مثبتًا

من Terminal داخل مجلد المشروع، نفّذي:

node server.mjs

ثم افتحي http://127.0.0.1:5500. لا تحتاجين إلى تثبيت حزم npm.

لا يكفي فتح index.html بالنقر المزدوج؛ استخدمي الخادم المحلي. على الجوال يلزم رابط HTTPS مستضاف، وليس عنوان localhost الخاص باللابتوب.

أول تجربة

اختاري التخرج أو السفر أو التصوير اليومي، ثم اختاري صورة. شغّلي الكاميرا ليظهر المحيط الأبيض. اسحبيه واضبطي حجمه ثم خذي مكانك داخله. استخدمي المؤقت للتصوير. المساعدة الذكية اختيارية، والصورة المحفوظة بدون الخطوط.

ملف README.md يحتوي شرح الملفات وحلول المشكلات. ملف PROJECT_NOTES.md يحتوي ملخصًا جامعيًا وخطة عرض وتقييم.

نموذج جامعي مستقل وغير تابع لسامسونج أو هواوي. نسبة التقارب ليست تقييمًا لجمال الصورة. فُحص منطق المقارنة آليًا؛ اختبري الكاميرا على جهازك قبل العرض الجامعي.
